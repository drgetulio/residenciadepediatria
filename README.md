# residenciadepediatria

## Site para a Residência de Pediatria do Hospital Materno Infantil de Brasília

Este repositório contém o código-fonte do site para a residência de pediatria do Hospital Materno Infantil de Brasília. O site foi desenvolvido utilizando Pure.css e possui as seguintes características:

- Menu lateral
- Responsividade
- Páginas dos setores do Hospital:
  - Emergências
  - Ala A
  - Ala B
  - DIP
  - Neonatologia
  - Medicina Intensiva Pediátrica
- Boa navegação voltada para residentes de pediatria (R1, R2 e R3)
- Páginas para acessar o Google Classroom e ferramentas de cálculo para prescrição pediátrica

## Como executar o site localmente

Para executar o site localmente, siga as instruções abaixo:

1. Clone o repositório:
   ```
   git clone https://github.com/drgetulio/residenciadepediatria.git
   ```

2. Navegue até o diretório do projeto:
   ```
   cd residenciadepediatria
   ```

3. Abra o arquivo `index.html` em seu navegador preferido.

Pronto! Agora você pode navegar pelo site localmente.
